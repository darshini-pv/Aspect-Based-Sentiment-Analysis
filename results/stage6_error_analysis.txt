6. INTERPRETATION AND LIMITATIONS
----------------------------------------------------------------------

This analysis examines the errors made by the selected Baseline Linear SVM on the original held-out test set.

Class-wise error statistics help identify which sentiment categories are more difficult for the model to classify.

The conflict class has very few test examples. Its evaluation metrics should therefore be interpreted cautiously.

Neutral sentiment may be confused with positive or negative sentiment when the review language contains mixed or subtle opinions.

The project uses provided aspect terms. It classifies the sentiment associated with a given aspect; it does not independently extract aspect terms.

This is an academic machine learning experiment and is not a clinically or commercially validated system.
